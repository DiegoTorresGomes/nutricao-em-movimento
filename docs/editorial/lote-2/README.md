Os seis títulos atuais foram mantidos como proposta de H1; o corpo tem apenas H2/H3. Cada ficha oferece meta title, meta description e excerpt próprios, sem clickbait. Slug/URL, ID, status, categoria, views e datas não têm alterações propostas nesta fase. editorialUpdatedAt não recebeu data artificial; só pode ser definido quando uma versão aprovada for efetivamente aplicada.

**Limite de metadata:** o código atual usa article.title e, para estes seis, article.description em generateMetadata. seoTitle e seoDescription salvos não são automaticamente exibidos. A distinção entre excerpt e meta description permanece como proposta revisável; uma etapa futura precisa definir aplicação coerente sem prometer resultado que o template não suporta. Nada foi alterado no template.

O corpo novo não deve ser aplicado sem sua bibliografia. Infográficos, tabelas visuais e alts antigos não podem ser mantidos mecanicamente se contradisserem a revisão (especialmente escala e promessa de benefícios do #1).
